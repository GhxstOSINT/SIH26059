# Antarctic ConvLSTM research checkpoint

- **Origin:** Dong et al., *Antarctic sea ice prediction with a convolutional long short-term memory network*, Ocean Modelling (2024), DOI 10.1016/j.ocemod.2024.102386.
- **Artifact:** author-published Zenodo v2 record, DOI 10.5281/zenodo.11234961; record license CC BY 4.0. The checkpoint is `ConvLSTM.params`.
- **Integrity:** SHA-256 `26ea046d9b097f56853a0f705eed933477b0c34b5f4f510c27183292da23c4db`; archive and test-data hashes are recorded in `work/datasets/convlstm-paper/ConvLSTM/manifest.json`.
- **Architecture evidence:** safely inspected state dictionary; five ConvLSTM layers with hidden channels 8, 8, 4, 2, 1; six input channels; 5×5 kernels. The paper pipeline uses a 90-day sequence.
- **Intended task:** daily Antarctic sea-ice concentration prediction. This is not a route planner, iceberg predictor, or navigation authority.
- **Training/evaluation described by paper:** NSIDC-0051/0081 passive-microwave products for 1989-2016 training and 2018-2022 evaluation, remapped to a 100-km grid. The preprint describes six inputs (daily SIC, daily climatology, daily standard deviation, annual sine/cosine and a land mask), a 90-day sequence, one-step output and an autoregressive rollout. See the [paper](https://doi.org/10.1016/j.ocemod.2024.102386) for reported methodology and skill.
- **Known limitation:** the published package includes weights and `testing_set.nc`, but not the full original training archive or all preprocessing parameters needed for faithful inference. G02202 is a distinct, separately processed CDR but shares passive-microwave source lineage with the paper's inputs; it is not an independent source-family validation. An approximate local compatibility probe is dramatically worse than persistence and is explicitly not valid model-skill evidence. The Southern Passage API does not load this checkpoint. Do not use until input preprocessing, masking, normalization, autoregressive rollout and paper-reported metrics have been independently reproduced on the exact paper data.
- **Reuse:** attribute the authors and comply with CC BY 4.0 and any separate data terms. Preserve the manifest and verify hashes after transfer.
