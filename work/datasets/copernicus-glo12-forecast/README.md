# GLO12 bulletin included with the service

Only the 11 November 2026 bulletin is tracked here: four original daily forecast NetCDF files for leads 1, 3, 5, and 7, plus their checksum and capture-provenance manifests. The packaged API uses these files to verify and report the latest bulletin. Older bulletins and the larger research archive remain local.

These forecasts are regional environmental context, not iceberg observations or navigation clearance. The repository also includes a much smaller Peninsula–Weddell Parquet derivative for analysis and distribution; that derivative does not replace the original NetCDF files for exact source checks.

Source: [Copernicus Marine Global Ocean Physics Analysis and Forecast](https://data.marine.copernicus.eu/product/GLOBAL_ANALYSISFORECAST_PHY_001_024/description), daily dataset `cmems_mod_glo_phy_anfc_0.083deg_P1D-m`, version `202406`, DOI [10.48670/moi-00016](https://doi.org/10.48670/moi-00016).
